# CardioRisk AI 🫀
### Clinical Decision Support System (CDSS) for Cardiovascular Risk Stratification

**CardioRisk AI** — це автономна медична веб-система підтримки прийняття клінічних рішень для оцінки 10-річного серцево-судинного ризику, що базується на моделях машинного навчання (XGBoost) з повною інтерпретованістю рішень (Explainable AI / TreeSHAP).

---

## 🌟 Основні можливості

- **Дворівнева діагностика:**
  - 🟢 **Скринінговий режим (Для пацієнта):** 12 базових факторів способу життя та антропометрії для швидкої первинної самооцінки без потреби у лабораторних аналізах.
  - 🩺 **Клінічний режим (Для лікаря / CDSS):** 23 поглиблені лабораторно-інструментальні біомаркери (тонометрія, розширена ліпідограма, глікемія, ШКФ нирок, ЕКГ, клінічні симптоми).
- **Пояснюваний ШІ (Explainable AI):**
  - Персоналізований факторний аналіз за допомогою **TreeSHAP Waterfall**.
  - Ранжування факторів за внеском у підвищення ризику та захисними властивостями.
- **Контрфактичне моделювання (What-If Симулятор):**
  - Інтерактивна симуляція впливу терапевтичних заходів і зміни способу життя (нормалізація тиску, статинотерапія, корекція ваги).
  - Ранжований список найефективніших цільових інтервенцій із кількісним розрахунком зниження ризику.
- **Генерація офіційного висновку (PDF Report):**
  - Експорт консультативного кардіологічного висновку формату A4 відповідно до стандартів ESC / AHA / ВООЗ.

## 🚀 Швидкий запуск

### Варіант 1: Через Docker (Рекомендовано)

```bash
docker compose up -d
```
Після запуску відкрийте у браузері: `http://localhost:8501`

### Варіант 2: Локальний запуск (Python 3.10+)

1. Встановіть залежності:
```bash
pip install -r requirements.txt
```

2. Запустіть додаток Streamlit:
```bash
streamlit run app.py
```

## 🛠️ Стек технологій

- **Мова програмування:** Python 3.11
